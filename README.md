# Bookstore Microservices

This project is a microservices-based system built using Spring Boot and Spring Cloud.

## Architecture
- API Gateway
- Eureka Server (Service Registry)
- Config Server
- Multiple microservices (User, Product, Order, etc.)

## Tech Stack
- Java 17
- Spring Boot 3
- Spring Cloud
- Docker
- PostgreSQL

## Structure
bookstore-microservices/
├── services/
├── api-gateway/
├── eureka-server/
├── config-server/
├── common-lib/
├── infrastructure/
